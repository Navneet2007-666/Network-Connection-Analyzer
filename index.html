Graph

A network is a graph G = (V, E). V is the set of devices and E is the set of connections between them.

Adjacency list

Each device stores the list of devices it is directly linked to. Memory use is O(V + E).



Depth-First Search
DFS visits a device, then goes as deep as possible along each unvisited neighbor before backing up.


DFS(graph, start):
  stack ← [start]; visited ← {}
  while stack not empty:
    u ← stack.pop()
    if u in visited: continue
    visit(u)
    for v in graph[u] (reverse order):
      if v not in visited: stack.push(v)


Example: with A–B, A–C, B–D, DFS from A visits A, B, D, C.


Connected components
A component is a group where every device can reach every other. Run DFS from each unvisited device; each run finds one component. An isolated device is a component of one.
